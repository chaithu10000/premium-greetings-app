
# Technical Approach

## Authentication
Firebase Authentication is used for:
- Google OAuth
- Guest Login

## Overlay Logic
The greeting card is built using layered absolute-positioned elements.
User image and name are dynamically injected.

## Export Engine
html2canvas converts DOM into downloadable PNG.

## State Management
Zustand manages lightweight global state.

## Scalability
Future scaling can include:
- Cloudinary
- Firebase Firestore
- Stripe/Razorpay
- AI Wishes Generator
- Admin CMS

## Challenges
- Responsive overlay rendering
- Image export quality
- Native sharing compatibility


# Premium Greetings & Wishes App

Production-ready internship submission for a customizable Greetings & Wishes platform.

## Features
- Google OAuth Authentication (Firebase)
- Email/Password Authentication
- Guest Login
- Personalized Greeting Generation
- Dynamic Overlay Engine
- Premium Templates
- Subscription Popup UI
- Download & Native Share
- Responsive UI
- Category Filtering
- Modern Dashboard
- Protected Routes
- Zustand State Management

## Tech Stack
- React + Vite
- Firebase
- Tailwind CSS
- React Router DOM
- html2canvas
- Zustand
- Framer Motion

## Installation

```bash
npm install
npm run dev
```

## Firebase Setup

Create Firebase Project and enable:
- Google Auth
- Email/Password Auth

Add credentials inside:
`src/config/firebase.js`

## Demo Flow
Login -> Dashboard -> Premium Popup -> Personalization -> Share/Download
